📂 Python File Handling Project

A beginner-friendly Python project that demonstrates the basic concepts of file handling. This application allows users to perform essential file operations through a simple menu-driven interface.

🚀 Features
Create a new file
Read file contents
Update existing files
Delete files
Interactive command-line interface

🛠️ Built With
Python 

📋 Available Operations
Press 1 for creating a file
Press 2 for reading a file
Press 3 for updating a file
Press 4 for deleting a file

▶️ Running the Project
python main.py
